# H100 Decode Results (April 12, 2026)

Status on April 12, 2026:

- the older Mosaic `baseline`, `latency`, and `throughput` families are still structurally uncompetitive
- the new env-gated Pallas Mosaic `throughput_v2` partials kernel now clears the primary six-shape H100 synthetic gate
- the new kernel is numerically close to the `blockwise` reference on all primary rows
- a short real-model runtime probe moved in the same direction
- auto-selection now uses an explicit validated canary table for the proven region, and only when the Mosaic `throughput_v2` env gate is enabled

This note supersedes the earlier same-day conclusion that `blockwise` remained the only viable direction. That conclusion was true for the old bridge families. It is no longer true for the new `throughput_v2_mosaic` path.

## Code State After Session B

The key implementation changes behind the winning path are:

- `throughput_v2` uses a bridge-free plan and does not route through the old batched core
- the experimental kernel is Pallas Mosaic GPU only
- the old stable JAX `throughput_v2` path remains as the fallback implementation
- auto-selection now checks an explicit validated canary table first when the Mosaic `throughput_v2` env gate is enabled
- the initial built-in canary table contains only:
  - `512 x 128 x 16 x 256`
  - `512 x 128 x 32 x 256`
  - `512 x 128 x 64 x 256`
  - `1024 x 128 x 16 x 256`
  - `2048 x 128 x 16 x 256`
  - `4096 x 128 x 16 x 256`

That means the path is no longer explicit-only, but it is still intentionally narrow, table-gated, and protected by the env gate:

- `NANOVLLM_JAX_ENABLE_THROUGHPUT_V2_MOSAIC=1`

## Bottom Line

The final April 12, 2026 conclusion is:

1. do not promote the old bridge families
2. do promote the new `throughput_v2_mosaic` path inside the validated region
3. keep the env gate in place for now
4. use the six-row synthetic gate plus correctness and short runtime agreement as the current promotion evidence

This branch is no longer in the state described by the initial expert packet. The follow-up Mosaic kernel bring-up materially changed the outcome.
