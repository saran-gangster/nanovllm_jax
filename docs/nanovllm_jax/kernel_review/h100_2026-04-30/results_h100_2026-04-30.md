# H100 throughput_v2 Speed-Window Validation - 2026-04-30

## Summary

This run validated the `throughput_v2_mosaic` speed-window plan on an NVIDIA H100 80GB HBM3 pod at repo SHA `1055bbb`.

The synthetic 10-row promotion gate passed all rows with `throughput_v2_mosaic` faster than `blockwise`, finite outputs, and max absolute diff no larger than `9.765625e-4`.

The real-model runtime gate showed a strong speed improvement, but the strict gate failed because token identity did not hold on the third deterministic prompt. That failure came from a tiny forced real-model batch of 3, outside the synthetic table-gated canary region. Do not remove the env gate or broaden rollout from this result.
